This is a sample post that shows how articles are laid out. To add a new one, drop a Markdown file into `src/content/posts/en/`.

## Why Astro

- Built-in i18n routing
- Posts written in Markdown
- GitHub repositories pulled in at build time

```js
const greeting = 'Hello, world';
console.log(greeting);
```

> The Chinese version lives in `src/content/posts/zh/` under the same file name, so the language switch links them together.
